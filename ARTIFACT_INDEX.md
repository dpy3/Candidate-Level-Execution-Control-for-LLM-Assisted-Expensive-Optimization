## Exclusion boundary

Large raw run trees, direction/proposal caches, unredacted API responses, credentials, temporary LaTeX files, and bytecode are not duplicated in this public snapshot. Frozen processed reports and protocols are public; live recapture requires external service access. The full local raw directories remain under `paper/q1/experiment_outputs` and must be deposited separately if the journal requests them.
