# Data and code availability

This public software release accompanies the manuscript and is available at https://github.com/dpy3/Candidate-Level-Execution-Control-for-LLM-Assisted-Expensive-Optimization. It contains the curated optimizer and CSA implementation, offline experiment runners, tests, processed reports, frozen protocols, an artifact index, and a SHA-256 manifest. The unchanged primary evidence archive and the separately dated mechanism-audit addendum are submitted as companion supplementary files.

Cached semantic proposals permit offline replay without new model calls. Live proposal capture requires a separately configured external model service and reviewer-supplied credentials. API keys, unredacted service responses, local environment files, bytecode, manuscript source, manuscript source and local absolute paths are excluded from this release.

The repository is versioned with Git and released under the MIT License; a DOI can be added after repository archival.
